# 《雨站》：晚点五十分钟

状态：已实现（`registry/apps/rain-station` 3.0.0）。剧本本身在 `registry/apps/rain-station/src/story.js`，那里是唯一的原文（中英两种语言）；
这份文档只记为什么这样写，给想在 Lo-PDA 上写故事的人参考。

3.0.0 整个换掉了 2.x 的故事（雨夜小站、十年前的旧车票、七章五个结局）。旧故事的存档键 `vn`、`chapters` 留在原处，新版本不读、不写、不删。

## 一句话

八月底的雨夜，爸骑摩托送你去山里的小站坐夜车上大学，车晚点五十分钟。

## 为什么是这个故事

- **短**：约 95 句，八到十分钟读完。手机上的故事，一次坐车、一次排队就该读完。
- **真**：没有悬疑、玄幻、巧合，每个细节都可能是真的：塑料布捆三道的箱子、按一按口袋确认身份证、剥得干干净净的鸡蛋、早就不卖的站台票、发短信不打标点的父亲。
- **不说破**：没有人说“我爱你”“我舍不得”。父亲的感情全在他做的事里，最后由别人（老周、妈的短信）说出一半，剩下一半留给读的人。

## 埋下和收回

一个短故事靠前面埋的东西在后面响起来：

| 埋下 | 收回 |
|---|---|
| 爸一遍遍问票、身份证 | 老周：他昨天就冒雨来问车几点到 |
| 老周：七号车厢“大概在雨棚中间，车不一定停得准” | 七号车厢停偏了二十米，爸扛着箱子跑 |
| 爸在站台上挪半步，“就这儿” | 他准备了一切，车还是停在别处 |
| 车窗外柱子上刷着白色的“3” | 最后一条短信：“七号车厢停3号柱子 / 下回我站那” |
| 鸡蛋：你说不饿，他塞进背包侧袋（或者你戴着耳机，看见他往侧袋里塞了什么） | 半夜饿醒，鸡蛋凉透了；妈的短信：“他让我问你，鸡蛋吃了没” |
| 妈没来，“来了要哭” | 妈的短信替爸把话说出来 |

最后一句“下回我站那”不提想念，只说他已经在为你回来那天做准备。

## 选择

两次选择，只改说法，不改结局。少分支是故意的：故事的力量在细节，不在岔路。

| 选择 | 标记 | 变化 |
|---|---|---|
| 戴上耳机 / 陪他坐着 | `phones` / `sat` | 你看见他和老周说话、往你包里塞东西（雨声变小）；或者你听他问食堂贵不贵、看他剥鸡蛋。老周的话跟着变一句 |
| 拉开车窗 / 隔着玻璃 | `open` / `glass` | 你说出“爸，回去吧”；或者他在窗外说了很长一句，你没看懂。妈的短信跟着变一句 |

## 写法（给后来的人）

- `story.js` 是从上到下的一张表，没有跳转。选择设一个标记，带 `when` 的步骤只在那个标记设了时才读。
- 画面在 `scenes.js`：每个场景从 `stage` 画出来（爸坐着还是出去了、车开到哪儿、窗开没开），故事只改 `stage`。
- 存档是表里的位置加标记，键是 `story`。改了表的形状就把 `player.js` 的 `SAVE_VERSION` 加一：旧位置会被搁在一边，故事从头开始，不会读到错的地方。
- 每句话在 160 像素宽的框里三行一页，中文一行约 11 个字。一句话最好一页说完。
- 结尾卡片放一遍原创的慢曲《三号柱子》（`src/music.js`，约 44 秒，不循环），回到标题时停。曲子必须是自己写的或公有领域的，流行歌哪怕一句也不行。
