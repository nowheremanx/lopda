## 不变的东西（写给实现的人）

- `runtime/chip.js`、`PAD.music`、`PAD.sfx`、`PAD.ambience` 的行为一个字节都不改（已有 app 依赖它，随 `lopda/1` 冻结）。
  四轨机的合成器是新文件，可以调用 chip.js 导出的函数，不改它。
- 商店 app 的 `mic` 权限仍然只给音量和音高，不开放录音；不加任何 PAD 接口。
- `core.js` 的 audio session 规则不变：平时 `"ambient"`，只有录音的那段时间 `"play-and-record"`，每条退路都设回来（第 23 节）。
- 四色、`putImageData`、44 px 触控目标、UI 文字都在 `strings.js`（中英两份）。

## 1. 轨道和声音

| 轨 | 音色（每轨 2–3 种） | 做法 |
|---|---|---|
| 鼓 | 芯片鼓、软鼓（闷底鼓 + 刷子军鼓） | 正弦滑音底鼓，滤波噪声军鼓 / 镲。4 种鼓：底鼓、军鼓、镲、打击 |
| 贝斯 | 三角波、圆滑正弦、拨弦 | 振荡器 + 低通；拨弦用 Karplus-Strong |
| 和弦 | 电钢琴、弦乐垫、方波和弦 | 简单 FM；去谐锯齿波 + 慢起音 |
| 旋律 | 方波、拨弦吉他、口哨 | 同上；正弦 + 颤音 + 一点噪声 |
| 人声 | 用户录音 | 第 4 节 |

- 全部合成，**不带采样**（没有许可问题，体积小）。
- 音符按**调式锁定**：网格上的音高是调式里的音级，不是半音。默认 A 小调五声，可换调。和弦格子里选 I–vi，自动用七 / 九和弦排列。
- **磁带味**一个旋钮（0–4 档）：低通、位深 / 采样率压缩、磁带摇摆（调制的小延迟）、底噪和唱片噼啪（可复用环境声的 crackle）、轻压缩。
  人声也过这条链。不暴露单个参数。
- **swing** 一个旋钮（0–60%，默认约 55%）。
- 可选一个背景环境声，直接用现有 6 个预设（雨声最合适）。

## 2. 界面（331×359，每屏一页，不滚动）

| 屏 | 内容 |
|---|---|
| 节奏器（第一次打开就在这） | 上方一排选鼓，下方 4×4 方块是这只鼓的 16 步（每块约 70 px）。正在响的那一步反色。播放 / 停止、BPM |
| 调音台 | 5 条轨一行一条：名字、音量、静音；顶部 BPM、调式、当前 pattern |
| 音符（贝斯 / 旋律） | 同样 16 个方块；点一块后在下方 8 个音（调式内一个八度）里选音高；再点一次删掉 |
| 和弦 | 每小节 1–2 格，点一格在 I–vi 里挑 |
| 弹奏 | 下半屏 8 个大琴键。循环播放时弹的内容量化到 16 分，写进当前轨（loop 叠加） |
| 歌曲 | A–H 八个 pattern 排成一串（最多 64 段），点位置换字母 |
| 录音 | 整首歌播放 + 录人声；先数一小节拍子；电平条；录完可以选一段重录 |

- 每屏右上角一个「?」重看教程。教程是几步：高亮一个区域 + 一句话 + 等用户做完这一下再下一步（参考拍照拼图的教程）。
- 四色：有音符 = 墨色，正在响 = 反色，空 = 底色。

## 3. 数据（给以后升级留的五条，只有这五条）

1. `song.json` 里的轨道是一个列表；「4 条乐器 + 1 条人声」是一个常量。
2. 音符时间用**每拍 96 格**存（`{t, len, deg, vel}`），界面对齐到 16 分（24 格）。以后加钢琴卷帘、自由时值、力度不用迁移。
3. 人声存成**片段列表** `{at, len, offset, file}`，不是一整条录音。重录一段 = 加一个片段。
4. 音色和效果做成登记表（`id → 构造函数`），加一种乐器就是加一项。
5. 工程带格式版本号 `v`；新版读得了旧工程，太新的拒收（同备份的规则）。

存储：工程文档 `studio/<id>`（{v, name, bpm, key, swing, tape, tracks, song, updated}）；人声片段在 `LopdaPlatform.files`
（单声道 16 kHz μ-law，3 分钟约 3 MB）。都自动进整机备份。录音**边录边分块写入**，被来电、锁屏打断时保留已录部分。

## 4. 录音

- AudioWorklet 取 PCM（不用 MediaRecorder）；录音前 `setSession("play-and-record")`，停后设回 `"ambient"` 并按 0.24.3 的做法重建 context，
  伴奏从当前拍子接着放（chip.js 已有 `beat()` / `from` 的思路）。
- **对齐**：第一次录音前做一次「对拍」校准（外放几声哔、麦克风听回来算往返延迟；戴耳机时让用户跟着哔声点 4 下），
  每种输出（外放 / 有线 / 蓝牙）存一个值。混音时扣掉，用户看不到。录完提供 ±10 ms 微调，这是唯一一个手动参数。
- 录音界面提示「戴耳机更好」；`getUserMedia` 关 echoCancellation / noiseSuppression / autoGainControl（是否生效看第 0 步）。
- 开麦时页面声音变小（第 23 节，已接受）：如果戴耳机时也变小，录音界面加一个只在录音时生效的「监听音量」。
- 静音键：保持 `"ambient"`，第一次播放时提醒一句「静音键开着就听不到外放」（网页读不到静音键）。
- `LP.keepAwake(true)` 防止录音时自动锁屏。

## 5. 文件

| 格式 | 方向 | 做法 |
|---|---|---|
| 工程 `.lopda-song`（zip） | 导出 + 导入 | `song.json` + 人声片段（μ-law WAV），用 `zip.js` |
| WAV | 导出 | OfflineAudioContext 离线渲染（含人声和磁带链），单声道 22.05 kHz 16 位 |
| MIDI（SMF type 1） | 导出 | 每条乐器一个 track，鼓在第 10 声道按 GM 鼓位，和弦展开成音符，swing 写进时值；人声不在里面 |
| MIDI | 导入 | 有损：量化到 16 分，压成鼓 / 贝斯 / 和弦 / 旋律，超出 8 个 pattern 截断并提示（`pad-audio.md` 9.3 的规则） |
| MML（加分） | 导出 | 压到 `PAD.music` 的 4 声道和芯片音色，复制到剪贴板，给社区 app 当配乐 |

- MIDI 读写和 WAV 写入是纯函数模块（`runtime/midi.js`、`runtime/wav.js`，node 测试），以后 `sdk/lo-midi.js`、`tools/midi2mml.mjs`、
  `PAD.music.render` 直接用。
- 不做：MP3 / M4A 导出（常见编码库 lamejs、ffmpeg.wasm 是 LGPL / GPL，不能用；浏览器自带编码以后再看）、MusicXML、DAW 私有工程、在线转换。

## 6. AI 辅助（第 34 节的 AI 线路）

- 和弦屏、音符屏的菜单里多一项「让 AI 写」：用户说一句话（「下雨天、慢一点、有点忧伤」），AI 回一段 JSON（调式内音级 + 96 格时值），
  程序校验后填进当前 pattern，用户再自己改。校验失败就说一句「AI 写的看不懂，再试一次」，不填半截。
- 发出去的只有：提示词、那句话、调式、BPM、轨道种类。不发录音、不发其他工程。
- 没有 key：同一个位置是「挑一个模板」，内置一组原创的和弦进行和节奏（和弦进行本身不受版权保护，模板仍然自己写）。
- 和其他 AI 功能一样：没有 key 的人看不到「让 AI 写」。

## 8. 第 0 步：iPhone 实测页

一个不合并的测试页（`runtime/studio-test.html`，像 PR #58 的 `sensor-test.html`），owner 在 iPhone 主屏 app 里按清单测，结果写回本文第 9 节。

页面上依次有这些按钮，每项把结果显示在页面上，并有「复制结果」：

1. **环境**：`AudioContext.sampleRate`、`baseLatency`、`outputLatency`（没有就写「无」）、`AudioWorklet` 是否存在、
   `MediaRecorder.isTypeSupported` 对 audio/mp4、audio/wav、audio/webm 的结果、`AudioEncoder` 是否存在、`navigator.audioSession` 是否存在。
2. **往返延迟**：外放 8 声短促的哔（间隔 0.5 秒），同时用 AudioWorklet 录麦克风，找每声的起点，报中位数和最大最小值。
   owner 分别在外放、有线耳机（手机麦克风）、蓝牙耳机下各测一次。
3. **跟拍校准**：戴耳机听哔，用户每听到一声点一次屏幕，报点击和哔的平均差。
4. **回声消除**：分别以 echoCancellation / noiseSuppression / autoGainControl 为 true 和 false 打开麦克风，显示 `track.getSettings()` 的实际值；
   外放一段循环伴奏的同时录 5 秒，录完播放，owner 听伴奏有没有被削掉、人声有没有忽大忽小。
5. **开麦后的音量**：放一段循环伴奏，按钮开 / 关麦克风。owner 分别在外放、有线、蓝牙下听声音有没有变小。
6. **长时间录音**：录 3 分钟，比对收到的样本数和时钟，报丢了多少；中途锁屏一次，看页面回来后的状态。
7. **静音键**：`"ambient"` 下放声音、开关一次麦克风后再放，owner 拨静音键看外放有没有声。

测试页只用来测，不考虑界面和四色。
