# 设计：滥竽充数（fake-yu）

状态：已实现，待审核。四色音游，160×144，用 A 键或触屏，讲南郭先生混进皇家乐队的故事。

## 1. 一句话

跟着乐队吹，别被国王发现——一个用“假装”当核心动作的单键节奏游戏。

## 2. 为什么是它

- **动作有戏**：别的音游要求“一直按对”；这里还要求“该停时停”。国王的大眼睛是第二套谱面，按错不是掉分，是露馅。
- **失败也好笑**：怀疑值满了不是 Game Over，是被侍卫叉出去。重来只要按 A。
- **四色够用**：宫廷、乐师、观众、乐谱卷轴都能用剪影和抖动排线画出来；高潮靠构图、闪屏、震动和人群，而不是颜色。
- **音乐是主角**：三首公有领域古典旋律，改成 4 声道 MML。玩家每一下“吹”都叠一个和旋律同音高的气声，命中时音乐和手感一起到位。

## 3. 核心循环

1. 乐谱卷轴从右向左走，音符到达嘴边的竖线时按 A（触屏：点画面）。
2. 长条音符按住 A，到尾再松；提前松会破音。
3. 国王的眼睛出现在卷轴上时，**不能按**。按了就涨怀疑。
4. 命中：连击、掌声、气圈、音高正确的“噗”声。漏掉：旋律少一个气口，怀疑上涨。
5. 怀疑满 100：被赶出宫。演完：按准确率、最高连击和剩余怀疑评级。

## 4. 三个曲目

| # | 曲目 | 原曲 | 教学点 |
|---|---|---|---|
| 1 | 小星星 | Ah! vous dirai-je, maman（法国童谣，1761，公有领域） | 单键、长音、第一次“别吹” |
| 2 | 欢乐颂 | 贝多芬第九交响曲第四乐章主题（1824，公有领域） | 更密的八分音符、两次长音、两次注视 |
| 3 | 山魔王的宫殿 | 格里格《培尔·金特》第一组曲（1875，公有领域） | 三段加速：四分音符 → 八分音符 → 高八度爆发 |

三首都是自己写的简化编曲，不改原曲署名；配器是方波主旋律、方波琶音、三角波贝斯、噪声鼓。

## 5. 画面

### 标题

- 宫廷舞台：两侧帷幕、顶部吊灯、台口。
- 中间一块木牌写「滥竽充数」，下面小字「南郭先生升职记」。
- 南郭在左下吹竽，指挥在右下挥棒，两人都跟着节拍动。
- 菜单三行：开始演奏 / 选曲 / 怎么玩。选中行反色。

### 演奏

```
0    HUD：曲名 · 连击 · 怀疑值（眼睛格）
16   皇家包厢：国王剪影，怀疑高时睁眼
32   乐谱卷轴：五线谱，音符从右向左，长条是按住
98   乐队席：五个剪影，南郭在最左，指挥在最右
120  观众席：两排脑袋，按拍点头
```

- 音符的纵向位置就是音高，横向位置就是时间；一眼能看出旋律走向。
- 国王注视时卷轴变暗、音符消失，中间睁开一只大眼睛，写「别吹！」；开始前两拍有警告。
- 命中时嘴边冒气圈，音符炸成小点；连击每 10 一次小闪屏，每 25 观众站起来。
- 怀疑值满时，全场转头，画面抖，侍卫的叉子从两边伸进来。

### 结算

- 观众鼓掌、撒纸屑，南郭鞠躬。
- 木牌：演出成功 / 被赶出宫。
- 得分、最高连击、准确率、剩余怀疑；右边盖一个 S/A/B/C 的戳。
- A 下一曲 / 再来一次，B 回选曲。

## 6. 手感

- 判定窗口：完美 ±100 ms，不错 ±200 ms；提前 200–350 ms 只提示“早”，不罚。
- 连击不设上限；漏一个只断连击，不会立刻失败。
- 怀疑值：漏 +9，杂音 +7，被国王看见 +16；每次命中 -1，慢速自然回落。
- 长音：按下开始，尾端 ±200 ms 内松手算完成；提前松 = 破音。
- 触屏：整个画面都是 A，长按就是长音；不需要找按钮。
- 手柄：A 吹，START 退出（确认），B 在菜单里返回。
- 每一下命中都有一声和音符同音高的短“噗”，完美更亮；漏掉是气声，不是刺耳错误音。

## 7. 技术

- `sdk/lo-game.js` 1.4.0，160×144 索引色画布。
- `PAD.music.play(song, {loop:false})` 播放 MML；谱面时间从同一个起点用 `game.time` 推算。
- `PAD.sfx` 自定义音效做气声；`game.shake` / `game.flash` 做打击感；无网络、无外部资源。
- 存档：每曲最好成绩和是否通关，`game.save("save", ...)`。
- 曲谱和谱面由同一份音符事件生成，避免“听到的”和“按的”对不上。
- 兼容没有 `PAD.music` 的旧 runtime：音乐静音，但谱面和判定照常，游戏可玩。
- 双语：`game.t`，中文默认，英文完整可用；manifest 带 `i18n`。

## 8. 不做什么

- 不做多轨、多键、滑条；一个 A 键就是全部。
- 不做联网排行、账号、每日任务。
- 不做原创长篇剧情；三句过场，演完就走。
- 不做校准滑杆；判定窗口已经够宽，先保证拿起就玩。
