# 设计草稿：倾斜感应和麦克风开放给 app

状态：草稿（2026-10-16），等 owner 确认。背景：owner 想让 app 开发更有趣，尤其是陀螺仪；GPS 决定不做（见第 8 节）。
商店的 app 跑在沙盒 iframe 里，自己申请不了传感器，所以由主程序（runtime）统一申请，再把整理过的读数经 PAD 转给 app，
和文件接口（`docs/design/pad-files.md`）同一个思路。

## 需要 owner 确认的事（先看这里）

| # | 问题 | 推荐 |
|---|---|---|
| 1 | 开放哪些 | **倾斜**（左右、前后）、**摇一摇**、**朝向**（指南针，拿不到时为空），和**麦克风的音量与音高**。不开放 GPS、原始音频、原始传感器数据 |
| 2 | 给 app 什么样的数据 | 主程序整理好的、粗一点的值：倾斜是 -1 到 1，按 1/32 一档取整；每秒最多 30 次。麦克风只给音量（0–1）和音高（Hz 或空），**永远不给录音** |
| 3 | 怎么申请权限 | manifest 声明 `"permissions": ["motion"]` / `["mic"]`；app 第一次要用时，机身上弹主程序自己的确认框，A 同意后再弹系统授权。同一个 app 同意过一次，以后不再弹机身确认框（系统授权什么时候再问由 iOS 决定） |
| 4 | 没有传感器的时候 | 桌面浏览器、拒绝授权、旧机型都有可能。SPEC 规定：用倾斜或麦克风的 app **必须也能用按键玩**，传感器只是另一种玩法 |

| 6 | 示范 app | 两个小的原创 app：**滚珠迷宫**（倾斜）和**吹蜡烛**（麦克风音量）；各自都能用按键玩 |
| 7 | 内置程序用不用 | 这一版不用。以后可以想（比如相机的水平仪） |

## 1. 读数

### 倾斜和朝向（`motion`）
- 来源：`deviceorientation`（beta 前后、gamma 左右，iOS 的 `webkitCompassHeading` 朝向）和 `devicemotion`（加速度，用来认"摇一摇"）。
- 给 app 的值（机器竖着拿，屏幕朝上）：
  - `x`：左右倾斜，-1（向左）到 1（向右），约 ±45° 到头；
  - `y`：前后倾斜，-1（上沿抬起）到 1（上沿压低），以"开始时的姿势"或 `zero()` 那一刻为 0（人很少把手机平放着玩）；
  - `heading`：0–359，正北为 0；拿不到就是 `null`。
  - 都按 1/32 一档取整（`x` 一共 65 档）。既有"老传感器"的手感，也让读数没法当成指纹用。
- `shake` 事件：短时间内加速度超过阈值，一次摇晃只发一次，两次之间至少隔 0.5 秒。
- 只在 app 显示在前台时发送；HOME、锁屏、切到别的程序时停。

### 麦克风（`mic`）
- 主程序用 `getUserMedia({audio})` 取声音，在主程序里算：
  - `level`：0–1 的音量（RMS 换算后取整到 1/32）；
  - `pitch`：主音的频率（Hz，整数），听不出来时是 `null`（用自相关法，50–1500 Hz）。
- 每秒最多 20 次。**声音数据不离开主程序**，app 只拿到这两个数。
- 只在 app 调用 `start()` 之后打开，`stop()`、HOME、锁屏、切走时立刻关掉轨道（手机状态栏的麦克风指示灯随之熄灭）。

## 2. PAD 接口（`lopda/1` 的增量，runtime 0.24.0 起；旧版本上是 `undefined`）

```js
// "permissions": ["motion"]
await PAD.motion.start()   // -> "on" | "denied" | "none"（没有传感器）
PAD.motion.stop()
PAD.motion.zero()          // 以现在的姿势为 y = 0
PAD.on("tilt", fn)         // fn({x, y, heading})，最多每秒 30 次
PAD.on("shake", fn)        // fn()

// "permissions": ["mic"]
await PAD.mic.start()      // -> "on" | "denied" | "none"
PAD.mic.stop()
PAD.on("sound", fn)        // fn({level, pitch})，最多每秒 20 次
```

- `start()` 什么时候调都可以：机身确认框和系统授权由主程序在**自己的**点击里发起（iframe 里的点击不算主程序的用户操作），所以 app 不用管手势。
- 没声明权限就调用：直接返回 `"denied"`，开发台里报错；检查工具（check-app.mjs）里报错，和 `files` 一样。
- `PAD.motion` / `PAD.mic` 是否存在就是功能检测：旧 runtime 上为 `undefined`，app 自动只用按键。

## 3. 权限和提示

- manifest：`"permissions"` 的允许列表从 `["files"]` 扩到 `["files", "motion", "mic"]`。
- 商店详情页写出来：「会用倾斜感应」「会用麦克风（只听音量和音高，不录音）」。
- 第一次 `start()`：机身上弹确认框（和文件确认框同样的样子），写这个 app 的名字和要用什么；A 同意（在松开时，触发系统授权），B 拒绝。
  同意过的记在主程序里（每个 app 一条），以后直接开；设置里可以看到并撤销。拒绝的这一次返回 `"denied"`，下次 `start()` 再问。
- 麦克风开着的时候，屏幕顶部状态栏显示一个小记号（四色），提醒"正在听"。

## 4. 开发台（sdk/dev.html）

桌面上没有陀螺仪和合适的麦克风场景，开发台要能模拟：
- 倾斜：一个小方块，鼠标拖动就是倾斜，松开回中；一个"摇一摇"按钮；朝向用滑块。
- 麦克风：音量滑块、音高输入框；也可以选"用电脑的麦克风"。
- 日志里显示每次 `start()` 和返回值。

## 5. SPEC 和规则

- SPEC 第 2 节（permissions）、第 4 节（输入：传感器只是另一种玩法，**必须也能用按键玩**，首屏说明怎么切换）、第 6 节（API）、新的 6.4 节（传感器）。
- `sdk/UI.md`：用倾斜的 app，屏幕上给一个"校准"（`zero()`）的入口；不要要求玩家把手机放平。
- `sdk/PROMPT.md`、`LO-GAME.md`：加上用法和例子（lo-game 可以加一个 `tilt` 便捷读数，另议）。

## 6. 示范 app（registry，原创）

| app | 玩法 | 按键玩法 |
|---|---|---|
| 滚珠迷宫 | 倾斜机身让小球滚到终点，躲开洞；几关；START 校准 | 方向键推小球 |
| 吹蜡烛 | 对着话筒吹，把一排蜡烛吹灭；吹得越久越响灭得越多；最后一关要用某个音高唱出来 | 按住 A 吹 |

两个都遵守 sdk/UI.md、四个色调、原创美术和声音。

## 7. 测试

- pad-shim 单元测试：`PAD.motion` / `PAD.mic` 的消息往返；没权限返回 `"denied"`；`zero()`。
- 主程序：取整、限速（每秒不超过 30 / 20 次）、摇一摇去抖、离开时停止（单元测试用假事件）。
- e2e：打桩 `DeviceOrientationEvent.requestPermission` 和 `getUserMedia`：确认框出现、同意后读数到达 app、HOME 后停止、没权限的 app 拿到 `"denied"`；检查工具对没声明权限的调用报错。
- iPhone 手动：见第 0 步的清单。

## 8. 不做的事

- **GPS**：照片和底片不带位置（darkroom.md 第 6 节的隐私原则）；1986 年的掌机没有 GPS；地名要联网查第三方。
- 原始音频、录音、原始传感器数据。
- 震动（iPhone 的网页不支持）。
- 内置程序这一版不用传感器。
