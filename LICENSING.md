identify this project. You may say your work is "based on Lo-PDA" or "for
Lo-PDA", and an app in the registry may say it runs on Lo-PDA. A fork or a
product built from this code that is published for others must use a different
name and icon, so nobody mistakes it for this project.

MIT 许可只覆盖代码，不覆盖名字。可以说「基于 Lo-PDA」或「为 Lo-PDA 开发」；但对外发布的 fork 或产品要换
名字和图标，以免被误认为是本项目。

## Apps in the registry: permissive licenses only

Every app in `registry/apps/` must declare one of these SPDX identifiers in its
`manifest.json`:

`MIT`, `0BSD`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Apache-2.0`, `CC0-1.0`, `Unlicense`

This keeps the whole registry redistributable together with the project, by
anyone, under terms at least as open as the project's own. `tools/check-app.mjs`
rejects any other license string. Authors keep their copyright.

  Project Authors) and VT323 (Peter Hull, The VT323 Project Authors), both SIL Open
  Font License 1.1: the WOFF2 files Google Fonts serves, unchanged (see

  `runtime/fonts/OFL-VT323.txt`. Since runtime 0.5.0 they ship with the handheld instead
  of loading from Google Fonts, so they work offline and no request leaves the device.
- China holiday data: statutory days off and make-up workdays from holiday-cn by
  NateScarlet, MIT License, the year files copied unchanged into
  `runtime/vendor/holiday-cn/` with its license file. The calendar may download a
  missing year's file from jsDelivr, at most once every 7 days and with nothing about
  the user in the request (see docs/decisions.md section 14).
- English-Chinese dictionary: `runtime/vendor/ecdict/` is an abridged ECDICT by
  skywind3000 (Linwei), MIT License, converted to StarDict by `tools/gen-ecdict.mjs`;
  licence files `runtime/vendor/ecdict/LICENSE` and `LICENSE-WordNet`. Review of the fields
  (runtime 0.7.0, docs/decisions.md section 15):
  - Kept: headword, Chinese senses, English senses, word forms (exchange). Corpus ranks (BNC,
    COCA) only choose which words go in and are not shipped.
  - Dropped: phonetics (crawled from various sites, per ECDICT's README), Collins stars and Oxford
    3000 marks (taken from commercial dictionaries), exam tags, and Chinese lines marked `[网络]`
    (web translations of unknown origin).
  - English senses: mostly WordNet 3.0 (ECDICT's README says it filled them from WordNet), some
    Webster's Revised Unabridged (1913, public domain). The WordNet licence asks for its notice on
    all copies, so it is kept next to the data and in NOTICE.
  - Chinese senses: ECDICT's author compiled them from a word list found online (EDictAZ) and exam
    vocabularies, and releases the whole as MIT. Where those lists came from cannot be checked
    further; dictionary senses are short factual glosses, and this is the residual risk we accept.
  - Word forms: generated by ECDICT from the BNC corpus with NodeBox / WordNet tools; this is data
    about English (running is a form of run), not a copy of either tool.
  The dictionary program only imports other dictionaries the user brings. It does not ship, link
  to or recommend any.
- Sample books: `runtime/books/alice.txt` is Lewis Carroll's *Alice's Adventures in Wonderland*
  (1865, public domain), taken from Project Gutenberg eBook #11
  (https://www.gutenberg.org/ebooks/11, plain text UTF-8). `runtime/books/lunyu.txt` is the
  Analects (《論語》, Traditional Chinese, public domain), taken from Project Gutenberg eBook #23839
  (https://www.gutenberg.org/ebooks/23839, "Lun Yu", plain text UTF-8). Only the public-domain
  text is kept: Project Gutenberg's header, footer, licence and trademark were removed from both,
  as were, for Alice, the edition line, contents list and illustration marker, and, for the
  Analects, the producer credit and a transcriber's note (an erratum already applied in the
  text). The Analects were taken from Wikisource before, which is CC BY-SA; Project Gutenberg's
  copy is used instead so the repository keeps to permissive and public-domain material. Both
  are plain text the reader imports like any other TXT file.
- No GPL code: it would turn the whole project GPL.
- No game ROMs are bundled or distributed. The cartridge player only plays files
  the user supplies. Do not add ROMs to this repository or to the registry.
