# 设计草稿：电子书阅读器 + 英汉词典（内置，联动记事本）

状态：owner 已同意推荐（2026-10-11）。词典见 decisions.md 第 15 节，阅读器见第 16 节（摘抄改在 START 上，B 保持"返回"）。
合成一份文档，是因为两者联动：读书时用文曲星式的光标选词，A 查词典，B 摘抄进记事本。
owner 的要求：阅读器的用户体验一定要好；吸引 e-ink 用户。

## 1. 阅读器

### 1.1 导入和存储
- 从文件导入（内置程序可以直接用 `<input type=file>`）。书存进 IndexedDB：原文件、解析后的章节、目录、阅读进度。
- **iOS 的存储回收**：Safari 会清理一段时间不访问的网站数据，但加到主屏的 PWA 不受这条限制。打开阅读器时调用
  `navigator.storage.persist()`；如果用户是在浏览器里直接打开的（不是主屏 PWA），书架上提示"加到主屏，书才不会被系统清掉"。

### 1.2 格式
- **TXT**：用 `TextDecoder` 先试 UTF-8，失败或乱码比例高时改用 GBK（老的中文 txt 大多是 GBK）。按"第 X 章 / Chapter X"
  这类标题自动分章，分不出来就按固定字数分段。
- **EPUB**：本质是 zip 包加 XHTML。用 `DecompressionStream("deflate-raw")` 解压（Safari 16.4 起支持），不引入第三方库。
  读 `content.opf` 得到章节顺序，读 nav/ncx 得到目录。正文只保留段落、标题、强调、换行；图片第一版不显示（以后可以抖动成四色）。

### 1.3 排版和翻页（体验的重点）
- 正文用**系统字体**，颜色只用四个色调（墨色字、纸色底）。完整的中文点阵字库有好几 MB，而且长时间阅读系统字体更舒服。
- **整页翻页，不滚动**：用 CSS 多栏布局分页（栏宽 = 页宽），总页数由内容宽度算出。和"硬件界面固定一屏"的规则一致。
- 翻页：点屏幕左右两侧、左右滑动、十字键左右都可以。点屏幕中间打开菜单（目录、字号、跳页、书签）。
- 字号 3 档、行距固定（少一个决定）。改字号后保持在同一段文字附近，不跳回章首。
- 记住每本书的进度（按章节 + 段落位置记，不按页码，改字号后仍然准确）。
- 页脚：章节名和本章页码（例如 12/40）。
- **e-ink 模式**（设置里一个开关，或者检测到 `prefers-reduced-motion` 时默认打开）：没有任何动画和过渡，翻页整屏重绘，
  不用灰度渐变，只用对比最强的两个色调。

### 1.4 书架
- 一屏一列，最近读的在最上面，显示书名和进度百分比。删除书需要二次确认。

## 2. 词典

### 2.1 格式和引擎
- 只支持 **StarDict**：`.ifo`（元信息）、`.idx`（词条索引）、`.dict` 或 `.dict.dz`（释义；`.dz` 是 dictzip，即带随机访问信息的 gzip，
  可以整体解压）。格式有公开文档，解析器自己写，预计几百行，不引入第三方库。
- 导入后把索引存进 IndexedDB，按词条建前缀索引，支持边输入边出候选。
- 查词顺序：精确匹配 → 词形还原（ECDICT 自带词形变化字段，例如 running → run）→ 前缀候选。
- 多本词典时，按用户排的顺序依次显示结果。

### 2.2 内置词典和许可审查
- **ECDICT**（https://github.com/skywind3000/ECDICT）：repo 标的是 MIT。但它的数据来源混杂：爬取的音标、柯林斯星级、牛津 3000 标签等，
  各自的许可不清楚。做法：
  - 只保留来源清楚的字段（词头、中文释义、英文释义、词频、词形变化），去掉柯林斯星级、牛津标签、考试标签和音标。
  - 只保留常用的约 2–3 万词，控制体积（预计压缩后 1–2 MB，放进离线缓存）。
  - 在 PR 里写一段许可审查的结论，LICENSING.md 和 NOTICE 里列出来源。
- **WordNet**（英英）：普林斯顿的许可很宽松，可以作为第二本内置词典。体积较大时可以不放进离线缓存，改成按需下载。〔可讨论〕
- **用户导入**：我们只提供导入功能，不附带、不推荐、不链接任何第三方词典。网上流传的 StarDict / MDict 词典大多是商业词典的盗版，
  这一点不在项目的责任范围内，但界面上也不要引导用户去找。

### 2.3 词典程序本身（文曲星式）
- 一个输入框，下面是候选列表，选中后显示可滚动的释义。左、右在当前候选之间切换，上、下按行对齐翻页并保留一行重叠；释义标题显示页码。返回后保留候选光标和列表位置。
- 释义文本暂不支持选择、复制或追加到笔记：词典先移除独立的文本选择，等阅读器提供可由两个程序共享的程序内选词，避免两套不同的选区体验。查词历史；**生词本**：有结果时在释义页按 START 加入，生词本里可以逐个复习（以后可以扩展成背单词）。
- 词典管理页列出内置和导入的每本词典及其启用状态。A 切换高亮词典的启用/停用状态；停用的书不参与候选、补全或 `LP.dict.lookup`（阅读器也使用这个设置）。所有书都停用时，主界面提示启用一本，而不是显示无匹配。
- 释义页按键：◀ 前词，B 返回，START 生词本（有结果时显示），▶ 后词；没有复制或笔记按钮。词典管理按键：A 启用/停用，▲▼ 选择，B 返回；上移、下移、删除、导入使用屏幕按钮。

## 3. 为什么不用系统查词

| | 系统查词（iOS 长按选词） | 程序内光标 |
|---|---|---|
| 词典质量 | 好（苹果的词典） | 取决于内置和导入的词典 |
| 复古感 | 差：蓝色选择柄、系统弹出菜单 | 强：文曲星、电子词典就是这样用的 |
| 跨设备 | 只有 iOS 有这套体验 | 所有设备一致，包括 e-ink 阅读器的浏览器 |
| 和翻页的冲突 | 长按容易误触翻页 | 没有 |
| 能做的事 | 只能查词 | 查词、摘抄、写心得 |

所以阅读器里关掉系统选择（`user-select: none`、`-webkit-touch-callout: none`），用程序内光标。

## 4. 光标、查词和摘抄

- 按 SELECT（或点菜单里的"选词"）进入选词模式，出现一个反色的方块光标。
- 英文按词移动，中文按字移动；十字键移动，**也可以直接点屏幕上的词，光标跳过去**（不然太慢）。
  按住 A 再移动可以扩展选区（选一个短语或一句话）。
- **A = 查词**：屏幕下半部分显示释义，可以翻页；B 关闭。释义页里再按 B 加入生词本。
- **B = 摘抄**：把选中的文字连同书名、章节，追加到记事本里一条叫《书名》的笔记中（没有就新建）。格式：
  ```
  《书名》 第三章
  「选中的原文」
  ```
  摘抄后可以直接输入一段心得，接在原文下面。
- 记事本里打开这条笔记就能看到所有摘抄和心得，这就是读书笔记。

## 5. 依赖

- 依赖"拆分 runtime"：阅读器、词典、记事本之间通过共享的 `LP` 对象互相调用（查词、追加笔记）。
- 记事本需要一个小接口：`LP.notes.append(title, text)`，按标题找到或新建笔记并在末尾追加。
