# 设计：滥竽充数（fake-yu）

状态：已实现 v2.0.0。四色节奏故事，160×144；A 吹竽、B 敲磬，摇一摇咳嗽、倾斜躬身；十首公有领域古典曲，三幕十章，四种结局。

## 1. 一句话

跟着三百人的乐队吹，国王睁眼时千万别动——一个用“假装”当核心动作，又让假装慢慢变成真本事的节奏故事。

## 2. 为什么是它

- **动作有戏**：别的音游要求“一直按对”；这里还要求“该停时停”。国王的大眼睛是第二套谱面，按错不是掉分，是露馅。
- **失败也好笑**：怀疑值满了不是 Game Over，是被侍卫叉出去；咳嗽和躬身是两个很没出息的保命动作。
- **故事有钩子**：宣王爱合奏，湣王只听独奏。三百人的掩护一夜之间消失，南郭必须决定继续装还是学一支真曲。
- **四色够用**：宫廷、花园、王座、月夜、宫墙、黎明都用剪影、抖动排线和构图区分；高潮靠眼睛、帷幕、闪屏和人群。
- **音乐是主角**：十首公有领域旋律改成 4 声道 MML；每一下“吹”都叠一个同音高的气声，命中时音乐和手感一起到位。

## 3. 核心循环

1. 乐谱卷轴从右向左走，音符到达嘴边的竖线时按 A（触屏：点画面）。
2. 长条音符按住 A，到尾再松；提前松会破音。
3. 菱形音符是磬，按 B（触屏：右下角「B 敲」）。
4. 国王的眼睛出现在卷轴上时，**不能按**。按了就涨怀疑；开始前两拍有警告。
5. 摇一摇机身（或 SELECT）咳嗽：怀疑 -14，每曲三次；倾斜机身（或按住 ↓）躬身：被看见时只涨一半怀疑，全程躬身还有加分。
6. 命中：连击、掌声、气圈、同音高的“噗”声。漏掉：旋律少一个气口，怀疑上涨。
7. 怀疑满 100：被赶出宫。演完：按准确率、最高连击和剩余怀疑评级。

## 5. 故事

### 人物

| 角色 | 作用 |
|---|---|
| 南郭 | 主角。不会吹竽，但很会站在人堆里。 |
| 齐宣王 | 爱听三百人合奏，好面子，赏罚都凭高兴。 |
| 齐湣王 | 宣王之子，只听独奏，冷而准。 |
| 乐正 | 乐队总管。规则、排练和怀疑都从他嘴里出来。 |
| 阿琴 | 同排乐师。最早看穿南郭，也是唯一愿意教他的人。 |
| 侍卫 | 怀疑满值时负责把南郭叉出去。 |

### 三幕十章

- **第一幕 · 三百人**（小星星、欢乐颂、绿袖子、卡农）：南郭混进合奏殿，升职、受赏、当上乐正副手。阿琴要他答应学一支真曲。
- **第二幕 · 一个人**（山魔王、土耳其、天鹅湖、匈牙利）：宣王去世，湣王即位，第一句话就是“寡人只听独奏”。南郭被点名单独吹，靠咳嗽和躬身硬撑。
- **第三幕 · 一支真曲**（致爱丽丝、小夜曲）：宫墙下的夜里，南郭第一次认真看谱。第九章演完后，玩家选择对湣王坦白或继续装；第十章按选择走不同开场。

每章有演前对话和演后对话，每幕开场有幕卡。故事进度、已看结局和真话/谎话选择都进存档。

### 四种结局

结局由“是否坦白”和“最后一曲是否演好”（失败或 C 评级算没演好）共同决定：

| | 演好 | 没演好 |
|---|---|---|
| **坦白** | 一支真曲：湣王让他明天还来，阿琴教他很多年 | 回乡：被赶出宫，在村口吹出第一个音 |
| **继续装** | 首席：成为宫廷首席，再也没吹过真曲 | 喂马：发去马棚，有一天吹对了，马抬起了头 |

看完结局后故事回到第一章，已看结局数保留在标题页。

## 6. 画面

### 标题

- 宫廷舞台：帷幕、吊灯、台口、花园花瓣；通关全部曲目后国王换成高兴的脸。
- 木牌写「滥竽充数」，下面小字「南郭先生升职记」和「三百人齐奏」。
- 南郭在左下吹竽，指挥在右下挥棒，四个乐师在台前跟着节拍动。
- 菜单三行：开始/继续故事、选曲、怎么玩；选中行反色，显示当前幕、章和已看结局数。

### 故事

- 五个场景：合奏殿（hall）、花园（garden）、王座殿（throne）、月夜湖（moon）、宫墙夜（night）、黎明（dawn）。
- 说话人用 48×58 的胸像：南郭、宣王、湣王、乐正、阿琴、侍卫各有帽子和胡子；旁白是一团墨。
- 幕卡：两侧帷幕扫入，大字幕号、幕名、一句题词。

### 演奏

```
0    HUD：曲名 · 连击 · 怀疑值（眼睛格）
16   皇家包厢：国王剪影，怀疑高时睁眼
32   乐谱卷轴：五线谱，音符从右向左；圆点是 A，菱形是 B，长条要按住
98   乐队席：五个剪影，南郭在最左，指挥在最右
120  触屏按钮：咳 / B 敲
```

- 音符的纵向位置是音高，横向位置是时间；B 音符固定在卷轴上沿，形状和位置都能区分。
- 国王注视时卷轴变暗、音符消失，中间睁开一只大眼睛，写「别吹！」。
- 命中时嘴边冒气圈，音符炸成小点；每 10 连击小闪屏，每 25 连击观众站起来。
- 怀疑高时国王睁眼、身体前倾；怀疑满时全场转头，画面抖，侍卫的叉子从两边伸进来。
- 每个场景有自己的背景：合奏殿的柱子与吊灯、花园的花枝、王座殿的冷墙、月夜湖的月影、宫墙夜的灯、黎明的山。

### 结算与结局

- 结算：观众鼓掌、撒纸屑，南郭鞠躬；木牌写演出成功/被赶出宫，列出得分、最高连击、准确率、怀疑、敲磬数和咳嗽数；右边盖 S/A/B/C 的戳。
- 结局：专属画面（真曲的黎明、首席的空乐队、回乡的孩子、喂马的马棚与灯笼）+ 结局标题 + 已看结局数，然后逐页旁白。

## 7. 手感

- 判定窗口：完美 ±100 ms，不错 ±200 ms；提前 200–350 ms 只提示“早”，不罚。
- 连击不设上限；漏一个只断连击，不会立刻失败。
- 怀疑值：漏 +9、破长音 +10、杂音 +7、被国王看见 +16（躬身时 +8）；每次命中 -1.6/-0.8，不在注视时每秒自然回落 0.55。
- 长音：按下开始，尾端 ±200 ms 内松手算完成；提前松 = 破音。
- 咳嗽：怀疑 ≥8 时可用，-14，冷却 6 秒，每曲 3 次；摇一摇和 SELECT 等价。
- 躬身：按住 ↓ 或前倾机身；注视期间累计躬身超过一半时长，额外 +180 分。
- 触屏：画面其余部分是 A，长按就是长音；底部两个按钮是「咳」和「B 敲」。
- 手柄：A 吹、B 敲磬/菜单返回、START 确认、方向键选择、SELECT 咳嗽、↓ 躬身。
- 每一下命中都有一声和音符同音高的短“噗”，完美更亮；漏掉是气声，不是刺耳错误音。

## 8. 技术

- `sdk/lo-game.js` 1.4.0，160×144 索引色画布；应用拆成四个源文件：
  - `src/music.js`：十首曲子的音符、MML 和谱面生成。
  - `src/story.js`：人物、三幕、十章文本、四种结局。
  - `src/art.js`：场景、人物、卷轴、粒子和结局插画。
  - `src/game.js`：场景流、判定、怀疑、感应、触屏和存档。
- `PAD.music.play(song, {loop:false})` 播放 MML；谱面时间从同一个起点用 `game.time` 推算。
- `PAD.sfx` 自定义音效做气声和咳嗽；`game.shake` / `game.flash` 做打击感；无网络、无外部资源。
- 感应：`permissions: ["motion"]`；进入演奏时 `PAD.motion.start()` 并归零，退出时 `stop()`。没有感应或未授权时自动退回 SELECT/↓，按键始终可用。
- 存档：每曲最好成绩、是否通关、故事进度、真话选择和已看结局，`game.save("save", ...)`。
- 兼容没有 `PAD.music` / `PAD.motion` 的旧 runtime：音乐静音、感应关闭，谱面和判定照常。
- 双语：`game.t`，中文默认，英文完整可用；manifest 带 `i18n`。

## 9. 不做什么

- 不做滑条、双押和多轨下落；A/B 两个键和一条卷轴就是全部。
- 不做联网排行、账号、每日任务。
- 不做分支大地图；故事是一条线加最后一次选择。
- 不做校准滑杆；判定窗口已经够宽，先保证拿起就玩。
- 不做原创配乐；十首都是公有领域古典旋律的简化编曲。
