# 设计：声音 `PAD.music` / `PAD.sfx` / `PAD.ambience`

状态：owner 已同意方向（2026-10-11），待实现。对应 `docs/decisions.md` 第 10 节「背景音乐」。
前身是 `pad-music.md`（只有背景音乐）；owner 问到人物受伤声、海浪瀑布等环境声之后，扩成三层。

## 已定的事

| # | 问题 | 结论 |
|---|---|---|
| 1 | 谁发声 | **三层都由 runtime 合成并播放，app 只提供内容**（乐谱、音效参数、环境声预设）。这样音量、静音开关、iPhone 静音键、切后台、退出 app 都由 runtime 统一处理 |
| 2 | 声音芯片规格 | 音乐 4 声道：2 个方波、1 个三角波、1 个噪声。致敬 GB 一代，但不模拟任何真实芯片 |
| 3 | 乐谱格式 | 文本 MML |
| 4 | 单独的音乐音量 | 不要。跟随总音量，音乐固定比音效低一档 |
| 5 | 原创 | 乐曲和音效必须原创，不允许扒谱（包括老游戏配乐）；公有领域的古典曲、民歌可以，注明出处。写进 SPEC 和 CLAUDE.md |
| 6 | 层数 | 三层：音乐、自定义音效、环境声。低保真采样（真人喊叫）先不做，见附录 |

## 1. 分工：app 写内容，runtime 发声

| 层 | app 提供什么 | runtime 做什么 | app 的自由度 |
|---|---|---|---|
| 音乐 | 自己写的乐谱（MML） | 用 4 声道芯片演奏 | 完全自由 |
| 自定义音效 | 自己设计的参数（波形、音高滑动、包络、时长） | 按参数合成这一声 | 很高；原来 10 种具名音效照样能用 |
| 环境声 | 选一种预设并给强度 | 合成并循环播放 | 只能从预设里选（以后可以考虑开放参数） |

SPEC 原来就允许 app 自己用 Web Audio（会绕过音量设置，要保持小声、只在用户操作后开始）。这条后路保留，但有了三层之后应当很少用到。

## 2. 音乐：`PAD.music`

```js
if (PAD.music) {
  PAD.music.play(song);              // 开始播放（替换正在放的曲子），默认循环
  PAD.music.play(song, { loop: false });
  PAD.music.stop();                  // 约 0.3 秒淡出
}
```

- 只有 `play` 和 `stop`。不回报播放位置（不支持音游式对拍）。同一时间只有一首。
- 乐谱：
  ```js
  var song = { bpm: 120,
    p1: "@2 v12 o4 l8 [cdeg a4 g4]2 >c2",   // 方波 1
    p2: "@1 v8  o3 l4 c e g e",             // 方波 2
    tri: "o2 l4 c c g g",                   // 三角波（低音）
    noise: "l8 [x r x x]4" };               // 噪声（鼓）
  ```
  音符 `c d e f g a b`，升降 `+ -`，休止 `r`；`o0`–`o7`、`< >` 定八度；`l4` 默认时值，音符后可跟时值（`c8`、`c4.`）；`&` 连音；
  `v0`–`v15` 音量；`@0`–`@3` 方波占空比（12.5/25/50/75%）；`[ ... ]n` 重复；噪声声道 `x` 短、`X` 长。
- 每首曲子最多 8 KB 文本、4 个声道。解析失败不播放，通过现有的 `error` 消息报告（开发台里看得到）。

## 3. 自定义音效：`PAD.sfx` 扩展

```js
PAD.sfx("hit");                                            // 原有的 10 种具名音效，不变
PAD.sfx({ wave: "noise", from: 900, to: 120, ms: 180,      // 自定义：受伤的"嘭"
          attack: 5, decay: 175, vol: 0.8 });
PAD.sfx({ wave: "square", duty: 2, from: 440, to: 880, ms: 90 });  // 跳跃
```

- 参数：`wave`（`square` / `triangle` / `noise`）、`duty`（方波占空比 0–3）、`from` / `to`（起止频率，Hz，中间按指数滑动）、
  `ms`（总时长，≤ 1500）、`attack` / `decay`（包络，ms）、`vol`（0–1）、`vibrato`（可选，颤音深度和速度）。
  参数越界时截到范围内，不报错。
- 用途：受伤、攻击、跳跃、爆炸、拾取，以及角色"说话"时逐字的哔声（不同角色给不同音高）。
- 现有的"每秒最多 20 个"限制不变。

## 4. 环境声：`PAD.ambience`

```js
if (PAD.ambience) {
  PAD.ambience("rain", 0.6);         // 预设名 + 强度 0–1；再次调用会平滑过渡到新的预设或强度
  PAD.ambience(null);                // 约 1 秒淡出
}
```

- 预设（第一版）：`rain`（雨）、`waves`（海浪，一阵一阵）、`waterfall`（瀑布，持续）、`wind`（风，忽强忽弱）、`fire`（篝火，噼啪）、
  `stream`（溪流）。都是滤波噪声加缓慢起伏，由 runtime 调好参数。
- 同一时间只有一种环境声。

## 5. 混音和声道

- 同时发声上限：音乐 4 声道 + 音效 2 个 + 环境声 1 个。第三个音效到来时挤掉最早的那个（真实芯片的做法）。
- 增益：音效最响；音乐约为音效的一半；环境声更低一些，保证不盖过音乐和提示音。
- 全部接到 runtime 现有的总增益上，跟随声音开关和 4 档音量；`navigator.audioSession.type = "ambient"` 不变，跟随 iPhone 静音键。
- 声音关闭时，乐谱照样往下"走"，打开后从当前位置接着放，像真机关掉音量一样。

## 6. 生命周期

- 退出 app、按 HOME、切换 app：音乐和环境声立即停止。runtime 已经为每次运行新建 iframe，停止逻辑挂在同一个地方。
- 页面切到后台（`visibilitychange`）：暂停，回来时继续（卡带机已有同样的处理）。
- iPhone 上第一次发声需要用户手势解锁 AudioContext：在解锁前调用的 `play` / `ambience` 先记下，第一次按键或触屏时再开始。

## 7. 代码放在哪

- 合成器、MML 解析器、音效合成、环境声预设写成一个独立文件 `runtime/chip.js`（ES5），runtime 和 `sdk/dev.html` 共用，
  保证开发台里听到的和真机一致。加进 index.html、sw.js 的 SHELL。
- `sdk/pad-shim.js`：新增 `PAD.music`、`PAD.ambience`，扩展 `PAD.sfx` 接受对象；postMessage 新增 `op: "music"` / `"ambience"`，
  限制调用频率（例如每秒最多 4 次 `music.play`、`ambience`）。
- `sdk/lo-game.js`：新增 `game.music(song)`、`game.ambience(name, level)` 包装，没有对应 API 时什么都不做。需要发布新版 lo-game。
- 不改 CSP、不改沙盒权限。
- SPEC.md（第 4、6 节）、LO-GAME.md、PROMPT.md 同步更新；原创要求写进 SPEC 的审核规则和 CLAUDE.md 的 License rules。

## 8. 测试

- MML 解析器、音效参数截断是纯函数，在 `node:vm` 里测。
- 合成部分在 Playwright 里用 `OfflineAudioContext` 离线渲染：有声音、长度正确、音量为 0 时静音、声道上限生效。
- 生命周期：e2e 里开始播放音乐和环境声、按 HOME，确认已停止。

## 9. 不做的事

- 音频文件、长采样、自定义波表（三角波声道固定）。
- 单独的音乐音量、均衡器、播放列表。
- MIDI 导入工具（容易诱导扒谱）。

## 附录：低保真采样（第 4 层，暂不做）

如果以后确实需要真人喊叫（"喝！"）：

- **格式故意低保真**：单声道、8 kHz、4 位、单段 ≤ 1 秒（约 4 KB，base64 约 5 KB）。4 位是 GB 波形声道的精度，听感粗糙，
  和合成的声音风格一致，也降低了搬运别人录音的意义。
- **API**：`PAD.sample.define(id, base64)` 启动时定义一次；`PAD.sample.play(id, {pitch})` 播放，可以变调。
- **runtime**：解码成 8 kHz 的 AudioBuffer（浏览器自动重采样），走音效的总增益，占用两个音效声道之一。
- **工具**：`tools/pcm4.mjs` 把 WAV 转成 4 位 base64 并截断到 1 秒；开发台可以试听。checker 检查单段时长和每个 app 的采样总量（例如 ≤ 64 KB）。
- **暂不做的原因**：技术上不难，难在许可。程序判断不了一段录音是不是原创，只能靠作者声明加人工试听；前三层都是"写出来的"，原创性一目了然。
