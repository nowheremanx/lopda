# 镇妖塔：故事圣经

给以后写正篇（第一章起）的人读，人或 agent 都一样。序章的台词在
`registry/apps/zhenyao-tower/src/story.js`，本文件写台词背后的设定，保证前后一致。
原创仙侠：不借用任何已有作品的名字、角色、情节。只做中文，每行最多 13 个字，台词要短。

## 1. 世界

- **青石镇**：山脚下的小镇，几十户人家，石板路，井在广场中间。夜里点灯笼。
  镇上的人知道塔里镇着妖，但几代人都没出过事，所以说起来像说天气。
- **镇妖塔**：镇北山顶的七层塔。不知道谁建的，镇上只说"一直在那里"。
  封印在塔里，松动时塔顶会发光，镇上的人都看得见。
- **守塔一脉**：住在镇北门附近，师父带一个弟子，负责看守封印。没有门派名字，也没有其他同门（至少主角不知道）。
- **法术**：五行（金木水火土），各有招式。"七级浮屠"是借塔本身的形来压妖，只有守塔的人会。
  正篇如果加新法术，仍按五行归类，大招保持唯一。
- **妖**：狐火、树魅、石傀、水魍、铜甲尸是塔里镇着的小妖，封印一松就跑出来。
  **蜃**是会造幻象的妖，住在水里，吐气成楼台人影。序章的 boss 是一只蜃妖。

## 2. 人物

- **阿砚**（主角）：守塔弟子，十六岁左右。正直、有正义感，做事认真，话不多。
  从小被师父养大，不知道自己的父母是谁。脖子上一直戴着一把小银锁，背面刻着纹样（见第 3 节）。
  师父叫他"砚儿"，镇上的人叫他"阿砚"，小孩叫"砚哥"。
- **师父**：守塔人，道号不在序章出现（正篇可以给）。话少，不爱解释。十六年前的冬天把还是婴儿的阿砚抱回镇上。
  被问到阿砚的来历时总是岔开话题。他知道多少，序章不交代。
- **婆婆**：镇上的老人，看着阿砚长大，记性时好时坏。她说的话可以当真，也可以当作老人记混了。
- **阿青**：镇上的小孩，爱开玩笑。"塔顶的光，也是骗人的吗？"是一句无心的话，呼应蜃妖的幻象。
- **樵夫**：山道上躲雨的人，只出现一次。
- **蜃妖**：序章的 boss。先变成师父的样子骗阿砚下塔，被识破（幻象没有影子）。
  临死前说阿砚"身上有我们的气味"、十六年前"被抱走的那个就是你"。死后留下一枚玉佩。

## 3. 纹样、银锁和玉佩

- **纹样**：三道水纹绕成一个圈，圈心是一只眼睛。
- **银锁**：阿砚从小戴着，婆婆说抱回来时就有。背面刻着完整的纹样。
- **壁画**：塔内中层的墙上刻着同样的三道水纹，圈心（眼睛）剥落了，只剩一部分。
- **玉佩**：蜃妖消散后留下。纹样和银锁一模一样。握在手里会发烫，能让伤口不疼（序章里只发生过一次）。
  阿砚把它藏进袖子里，没有告诉师父。

## 4. 序章的事件顺序

1. 夜里塔顶又亮了。阿砚去北门见师父。路上婆婆提到他被抱回来那年，正好是封印上一次松动那年。
2. 师父让他上塔查看。阿砚问起自己的来历，师父说"要下雨了，先上山吧"。
3. 塔外山道下雨。五场战斗，樵夫说狐火怕水。
4. 塔内一层、中层各三场战斗。中层墙上有缺了圈心的纹样，阿砚觉得眼熟。
5. 塔顶：蜃妖变成师父，被阿砚识破（没有影子），现出原形，战斗。
6. 蜃妖临死的话，玉佩，纹样和银锁一样。阿砚问"是幻术吗"，玉佩发烫，伤口不疼了。"我到底是……"
7. 天亮，塔下。阿砚对师父说"塔中一切如常，蜃妖已除"，手里攥着袖中的玉佩。师父停了一下："……嗯。下去歇着吧。"
8. 阿砚独自站在塔下，玉佩微微发光。序章完。

## 6. 隐瞒的动机（不点破）

阿砚隐瞒玉佩是他自己的决定，序章里不给"如实相告"的选项，也不解释原因。两种读法都要成立：

- **想要力量**：玉佩能治伤，阿砚感受到了它的力量。
- **想自己查清楚**：身世被触动，师父又一直回避，他不想再被岔开一次。

序章给两种读法各留一句（"伤口不疼了"和"我到底是……"），不偏向任何一边。正篇可以选一种，也可以两种都有。

## 7. "真相"的几种方向（只列选项，不定答案）

正篇写到身世时，从这些里选，或者组合。序章的台词和这几种都不矛盾，不要在正篇之前把它说死。

1. **阿砚是蜃族的孩子**：十六年前封印松动，一只蜃妖带着孩子逃出塔，被师父截下。
   师父杀了（或重新封印了）大人，把孩子抱回来养大。银锁是蜃族的信物。蜃妖说的是真话。
2. **阿砚是建塔者的后人**：纹样是当年建塔、封妖的一族的徽记，蜃妖认得它，因为正是这一族把它关进塔里。
   "有我们的气味"是幻术，故意让阿砚怀疑师父。壁画上被凿掉的圈心是那一族败落的痕迹。
3. **阿砚是封印的一部分**：十六年前封印松动，师父用一个婴儿（和那把银锁）补上了封印。
   阿砚离塔越远，封印越松；玉佩是另一半钥匙。蜃妖的话半真半假。
4. **一切都是蜃妖的幻象**：纹样相同是蜃妖在临死时造的幻象，玉佩是它留下的诱饵，
   为的是让守塔人师徒失和。玉佩的"暖意"是它残存的妖力在引诱阿砚。
5. **师父才是关键**：银锁本来是师父的东西。十六年前出事的是师父自己的家人，阿砚是谁的孩子另有答案。

不管选哪一种，下面几条不变：

- 师父没有恶意。他的隐瞒有理由，正篇可以让人不同意这个理由，但不要把他写成坏人。
- 阿砚的正直不变。隐瞒是一个人的心结，不是变坏的开始。
- 蜃擅长幻象，所以蜃说的话永远有疑点。

## 8. 写法

- 每行最多 13 个字（`tests/zhenyao-tower.test.mjs` 会检查）。一页两行，用 `\n` 分开。
- 叙述（没有说话人的框）只写看到的、听到的，不写心理。心理只通过阿砚自己说出来。
- 不用感叹号堆情绪，不用网络用语。省略号用"……"。
- 地名、人名不要和已有作品重名。新加名字前先搜一下。
