状态：已定（owner 2026-10-15）。owner 看过 PR #43 后提出：词典管理这类界面底部按钮和提示太挤；
A 键的文字在「启用 / 停用」之间变化，宽度一变，底部按键就在一行和两行之间来回跳；阅读器和词典都有游戏控制键，

## 1. 软键栏

模仿老 PDA 和文曲星的软键：屏幕最下面一条，每个位置对应一个实体键，写着这个键此刻的作用。

- **一行，四格，宽度相等，高度固定 44 px**。从左到右是 SELECT、START、B、A，和下巴上的按键左右顺序一致。
  每格上面一小行写键名（像现在 `.ck i` 那样），下面一行写作用。
- **作用文字最多 4 个汉字或 7 个英文字母**，超出就截断，永远不换行。所以文字怎么变，格子都不会变宽，整条栏也不会变成两行。
- **这一屏没用到的键，格子留空白**，只写键名、不写作用，位置照样留着。这样四个键永远在同一个位置，眼睛不用找。
- **暂时不能用的键**：作用文字变成深色，按下去播放 `err`。格子不消失，也不变宽。
- **点格子等于按那个键**，同一个处理函数，触屏和实体键的结果完全一样。
- **软键栏属于弹层、列表和对话框**。全屏视图不常驻软键栏：日历月历、阅读器书页（仅选字时显示栏）、相机和卡带都没有。一个界面里的两个格子不能做同一件事；如果 SELECT 只会重复 B，就留空。
- **方向键不写在栏里**：它们在每一屏的作用都是"移动"（列表上下选、正文翻页），说明一次就够了，写在「按键说明」里。
- **栏里只放按键**。页码"2/5"、章名、进度放标题栏；"导入的说明"这类文字只在空状态时出现在内容区，平时不占地方。
- 主程序提供一个函数 `LP.softkeys(容器, {select, start, b, a})`，每个键传 `{label, fn, disabled}` 或 `null`。
  各内置程序都用它，不再自己拼按钮。写在 `runtime/core.js`，样式在 `lopda.css`。

## 2. 超过四个操作的规则

| 层级 | 放在哪 | 例子 |
|---|---|---|
| 这一项的操作 | A 打开「这一项」的小菜单（列表，A 确认、B 返回） | 词典列表里的一本：启用 / 停用、上移、下移、删除 |
| 这一屏的操作 | START「选项」菜单 | 词典列表：导入词典；生词本：清空 |
| 返回 | B | 每一屏都一样 |
| 这一屏的特殊操作 | SELECT | 阅读器：选字；词条页：选字 |

只有一个操作时直接做，不弹菜单（比如词条页 START 就是加入生词本）。删除照旧要按两次确认。

## 3. 选字：一个模块，两个程序

阅读器 0.9.0 起的选字（decisions.md 第 17 节）是对的，问题只在于它的代码和阅读器的分页绑在一起，词典用不了。
把它抽成 `runtime/textsel.js`（ES5，挂到 `window.LopdaTextSel`），阅读器和词典的词条页都用它。

### 3.1 模块做什么，程序做什么

| 共用模块 `textsel.js` | 各程序自己 |
|---|---|
| 把一段 DOM 里的文字切成单位：英文按词，中文按字；扩到句（。！？!?… 和后面跟空格的英文句点）、扩到段 | 告诉模块这一页可见的范围（阅读器：当前页；词典：滚动区里看得见的部分） |
| 长按 0.45 秒开始选、拖动扩展，点一下结束 | 光标移出可见范围时怎么办（阅读器：翻页；词典：滚动一行） |
| 方向键移动光标（上下按视觉上的行），按住 A 加方向键扩展 | 选中后 A、START 具体做什么（见 3.2） |
| SELECT 在词 → 句 → 段之间切换 | |
| 选区画成反色（墨色底、纸色字），用 `<mark>` 包起来，结束时拆掉 | |
| 把选中的文字和它在原文里的位置交给程序 | |

### 3.2 选字时的按键：两个程序完全一样

| 键 | 作用 |
|---|---|
| ◀▶▲▼ | 移动光标；按住 A 时扩展选区 |
| A（按下后松开） | 查词：阅读器在下半屏显示词条（现状）；词典打开这个词的词条，B 退回上一层 |
| START | 小菜单：摘抄（写进记事本；阅读器还会在书里划线。词典的笔记记在《词典》这一篇，带上词条名），复制（只放进剪贴板）。A 确定，B 回到选字 |
| SELECT | 切换 词 / 句 / 段（软键上显示当前单位） |
| B | 取消选字 |
| 触屏 | 长按开始，拖动扩展，点一下结束；快速滑动在阅读器里结束选字并翻页；词典里拖到上下边缘并停住会一行行滚动 |

进入选字：长按正文，或者按 SELECT（光标落在可见范围里的第一个词）。

### 3.3 不做的事

- 不用系统的文字选择（整机关着，`body{user-select:none}`），不用浮动工具提示。
- 选区不跨页（阅读器现状）；词典的词条是一整段滚动文字，选区可以跨过看不见的部分，但光标走到边缘时滚动一行。

## 6. 测试

- 软键栏：每一屏四格位置固定；A 的文字从「启用」变成「停用」，栏的高度和每格宽度都不变；点格子和按实体键调用同一个函数；
  在 331×359 上每一屏的栏都是一行。
- 选字：阅读器现有的选字 e2e 原样通过；词典词条页长按选词、拖动扩展、SELECT 切单位、A 打开新词条、B 一层层退回、

  长词条上拖到框外停住，页面滚动、选区变长，松手就停。
